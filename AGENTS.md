# bindforge

BindForge is an open framework for creating, sharing, and translating game input bindings.

## Conventions

- **Semantic commits**: every commit message follows the Conventional Commits
  format — `<type>: <short imperative description>` (e.g. `feat: add retry
  strategy to sync client`). Common types: `feat`, `fix`, `refactor`, `docs`,
  `test`, `chore`, `build`. A scope is optional: `fix(orchestration): ...`.
